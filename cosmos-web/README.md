# Cosmos Compiler Web

Premium landing page for Cosmos Compiler - Stop $2M outages before they ship.

## Features

- 🎨 **3D Spline Background** - Interactive cosmic particle scene
- ⚡ **WASM Playground** - Compile Cosmos DSL in browser
- ⌨️ **Cmd+K Palette** - Command palette like Cursor/Linear
- 📊 **Scroll Animations** - Parallax effects with Framer Motion
- 🌊 **Glassmorphism** - Premium glass UI effects
- 📈 **Vercel Analytics** - Performance monitoring

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Spline (3D)
- Lucide Icons
- Vercel Analytics

## Quick Start

```bash
# Install dependencies
npm install

# Development
npm run dev

# Build
npm run build

# Preview
npm run start
```

## Deploy

```bash
# Vercel (recommended)
npx vercel --prod

# Or fork and deploy from vercel.com
```

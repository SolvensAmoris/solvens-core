# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to the project maintainer:

**Email:** luis@solvens.amoris

Please do not publish unpatched vulnerability details in public issues or discussions. Include the affected commit or version, the relevant component, reproduction steps, impact, and any proof-of-concept that can be shared safely.

Do not include live credentials, personal data, or third-party data in a report. If a report contains sensitive material, arrange a secure transfer channel before sending it.

## Response

Reports are reviewed by the maintainer. No fixed response or remediation time is guaranteed. Severity, exploitability, affected versions, and remediation status will be assessed before public disclosure.
